# Daily Task Planner

## 📝 Project Description

An interactive, browser-based productivity dashboard application designed to seamlessly manage daily assignments and micro-tasks. Built inside a modern user-centric interface, the platform allows users to dynamically document items, execute live search filtering queries, track state progress through independent listing channels, and persist state models across browser context switches.

## 🛠️ Technologies Used

- **Frontend Document Structures:** HTML5 (Semantic Structure)
- **Custom Layout Controls:** CSS3 (Custom Responsive Viewport Settings)
- **Core Application Architecture Engine:** Vanilla JavaScript ES6
- **Browser Data Storage Layer:** Web Storage API (`localStorage`)

## 📋 Features Met Per Requirements

1. **Live Date Interface Engine:** Automatically renders the current weekday and date format right under the main title header layout module.
2. **Task Insertion Pipeline:** Seamlessly registers task records into active memory tracks using the explicit input field or by pressing the `Enter` submission key.
3. **Dynamic Filtering & Live Search:** Features an active responsive filter text tracking model that updates your task visibility output arrays instantly as you type.
4. **Independent Progress Segments:** Separates operational task object arrays cleanly into individual `📋 Pending Tasks` and `✅ Completed Tasks` visualization modules.
5. **State Toggles & Strikethrough Typography:** Features quick button interactions to toggle items back and forth with customized descriptive style line overrides.
6. **Pop-up Window Inline Configuration Layer:** Integrates an overlay modal editing context box to rewrite item descriptions safely without losing background state tracking metrics.
7. **Aggregated Analytical Metric Footnotes:** Displays calculated totals containing all metrics variables (`Total`, `Pending`, `Completed`) updated in real-time at the base layout panel.

## 🚀 How to Run the Project

1. Download or clone this project repository workspace directory to your desktop environment.
2. Ensure you have your standard file layouts verified (`index.html`, `style.css`, and `script.js` all stored side-by-side inside the root folder).
3. Double-click or trigger the `index.html` file to run your app statically in your preferred local web browser browser window.
4. Add items, click the edit buttons, search for words, and check tasks off to view the layout animations.
